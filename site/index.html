From rule to refusal

A short path with evidence at every boundary.

Read the architecture →
  1. 1

    Approve and seal

    Hooks ship together as an immutable, content-addressed release. A byte or permission change produces a different identity.

  2. 2

    Install explicitly

    The operator sees the exact write set before Tama generates managed entrypoints and registers the macOS policy backend.

  3. 3

    Decide in session

    The supervised runtime loads one release, evaluates tool events, and publishes its identity and decisions for Tama to inspect.

  4. 4

    Control without drift

    Session enables bind to the session identity. Global recovery restores only from an integrity-checked release.
