Endings a report cannot replace

Part of enforcement control, completion enforcement.

block-stop-on-own-work reads the transcript at Stop — the final message, what the agent said and thought since the operator last spoke, and every earlier refusal, and the tool calls made since the operator last spoke — and refuses these endings, each quoted back in the refusal:

  • a capacity, budget or clock nobody set, given as the reason the identified fix is not built (remaining session capacity, brak czasu w tej sesji); a limit the operator wrote in their own last message passes;
  • a repository of this workshop, checked out under ~/Documents/CodingProjects/Wisent, named under Blokery as the place the fix has to be made while Następne kroki says none — the refusal names the checkout path;
  • the report a stop guard already refused, said again with a sentence moved (three-word runs compared; the refusal gives the share), whatever its Następne kroki say;
  • a line under Następne kroki that hands the operator a decision or a go-ahead about the work (Decyzja, czy budować te trzy zmiany, czy mam, potwierdź, whether to build, let me know) or announces the agent's own next move (Zbuduję, I will). A decision is refused even when the line begs or names a cost (Błagam o decyzję w sprawie kosztu …). The refusal quotes the line: block-stop-on-own-work: BLOCKED: under Następne kroki this report hands the operator a decision: "…". That decision is yours …
  • a report that begs but does not hand the operator exactly one command: under Następne kroki the begging carries one command written as a code span, and on macOS that command is what pbpaste returns, because the agent copied it with printf '%s' '<command>' | pbcopy before answering. Two commands, none, or a clipboard holding something else are refused: block-stop-on-own-work: BLOCKED: this report begs with 2 commands …, … begs with `…`, but the clipboard holds something else …
  • an answer that leaves work undone because something is paid, when nobody read the price (nie założyłem, bo jest płatny, did not create it because it costs): the provider's credit balance and the resource's price are read through the organization's accounts first, and the work is done within the free credits; block-stop-on-own-work: BLOCKED: this answer leaves work undone because of a cost: "…"
  • a Blokady/Blockers or Kolejne kroki/Następne kroki/Next steps line that begins as an empty value and adds commentary, or says only that the agent is not assigning the operator work (Brak przy zapisie defektu. Sam zapis nie jest jego naprawą., Nie wyznaczam Ci zadania.). Write exactly Brak./None. or name a concrete blocker.
  • a Blokady or Następne kroki line that gives the operator something to do: a condition on his action (Dopóki ich nie zainstalujesz …), an instruction (uruchom, zainstaluj, wyeksportuj, ustaw, you must) or a place he is sent to (w swoim terminalu). The agent gives the operator no tasks. When it is completely blocked it may beg (Błagam, I beg) with one command on his clipboard, as above; a report that begs is not refused by this rule.
  • an answer that says the operator never said something (nie ma takiego cytatu, you never said) from a turn whose tool calls include no oko transcripts search without --session: absence is stated only after every transcript was searched, and a partial, failed or timed-out search is reported as incomplete; block-stop-on-own-work: BLOCKED: "…" says the operator never said something, and this turn searched no transcript beyond one session …
  • an answer that admits a mistake (to było nieprawdą, nie przeszukałem, my mistake) from a turn that ran no oko defects record or oko defects note: the mistake is recorded before the answer, without being dictated; block-stop-on-own-work: BLOCKED: the answer admits a mistake ("…") and this turn recorded nothing about it …
  • a turn that ran oko defects record and changed no source — no edit, write or git commit since the operator last spoke: recording a defect starts its repair; block-stop-on-own-work: BLOCKED: this turn recorded a defect and changed no source for it …
  • an ending that restates one of the agent's last five answers to earlier operator messages — at least the same share of three-word runs as a refused report — from a turn that changed no source: a status list said again is not work, and the refusal sends the agent to the next open task; block-stop-on-own-work: BLOCKED: this ending restates an answer already given (…% of its word runs), and this turn changed no source …
  • a Blokady/Blockers section that names the machine's own build gate (blokada budowania, czeka na wspólny build, block-one-off-repairs): the gate holds builds until the work is repaired and blocks nothing the operator asked for; block-stop-on-own-work: BLOCKED: the Blockers section names the build gate ("…") …
  • an answer in another language than the operator's latest message. Each text of at least twelve words is assigned the language whose most frequent function words make up the largest share of it, which recognises Polish typed without diacritics too; block-stop-on-own-work: BLOCKED: the operator wrote in polski and this answer is in english …
  • a plan written under the heading for what was done (Co zrobiono, Co zrobiłem, Co zostało zrobione, What was done): trzeba naprawić …, a numbered infinitive item such as 1. Dodać …, do zrobienia or the announced future tense; that section reports what happened, in the past tense; block-stop-on-own-work: BLOCKED: the section for what was done carries a plan: "…"
  • an answer that scopes the work to one session — lista zadań tej sesji, Sesja ma jedno zadanie, usterki, na których pracuje ta sesja, this session's tasks: the work is every open task of every session and every open defect of every product; block-stop-on-own-work: BLOCKED: this answer scopes the work to one session: "…"
  • an ending written right after a stop guard refused the previous one, with no tool call between the two: whatever the refusal asked, the answer to it is work on the next open task or defect (oko transcripts tasks --open, oko defects list --open), not the same report edited to pass; block-stop-on-own-work: BLOCKED: a stop guard refused the previous ending and no tool call came after it …

What passes: a report that begs with one command on the clipboard; a report that says what changed since the refusal; and a quoted phrase, in „…”, "…", «…» or backticks, which is a report, not a reason. Each refusal starts a new attempt: what the agent says after a refusal is judged on its own, so one sentence cannot refuse every attempt after it. The real-binary journey is rust/crates/tama-hook-tools/tests/own_work_guard.rs (cargo test -p tama-hook-tools --test own_work_guard): ten cases, covering the six refusals and the passes above, including exact empty sections and begging.
