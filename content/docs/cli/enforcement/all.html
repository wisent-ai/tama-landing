tama enforcement all

Restores the all-hooks machine baseline without changing the separate emergency switch.

Invocation

tama enforcement all

The command takes no positional input or public options.

Output and state

Success begins Machine enforcement selection cleared; all <N> installed hooks are selected. Tama atomically writes hook-enforcement.json with mode 0600, mode: "all", an empty enabled array, the transition time, and the immediately preceding effective mode and ids in previous.

If emergency disable is active, all-hooks mode is retained but remains bypassed until re-enable succeeds. The emergency state is not changed by this command.

Refusals and failures

The command has no hook-id refusal. A registry or write failure prints enforcement: <OS/core error> to stderr, exits 1, and does not claim that the machine selection changed.
