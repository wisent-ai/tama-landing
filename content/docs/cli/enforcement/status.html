tama enforcement status

Reads the durable machine-wide hook selection and the emergency switch that can temporarily bypass it.

Invocation

tama enforcement status [--json]

The command takes no positional input. --json selects the structured status document.

Output and state

Text output reports mode: all or mode: only, selected hooks: <selected>/<installed> installed, either selected ids: all installed hooks or the selected id list, and emergency disabled: true or false. JSON reports mode, enabled, selectedHookCount, installedHookCount, emergencyDisabled, and an optional readError. The command is read-only.

Refusals and failures

A missing hook-enforcement.json is normal all-hooks state. Malformed or unreadable state still prints the fallback-all status, writes the following exact sentence to stderr, and exits 1:

Tama could not read the machine enforcement selection: <core error>. Falling back to all hooks.

The JSON result includes the same failure in readError. The dispatcher also falls back to all, never none.
