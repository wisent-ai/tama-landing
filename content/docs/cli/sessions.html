tama sessions

Reports every recorded live agent session and the hook state projected into its session-control record.

Invocation

tama sessions [--json] [--home <path>]

--home selects the home containing both Library/Application Support/Tama/session-control and the machine enforcement state; otherwise Tama uses HOME. --json prints the structured machine status and session array.

Output and state

Text mode begins machine enforcement mode=<mode> selected=<n>/<N> ids=<all or comma ids> emergency-disabled=<bool>, then prints each session's agent id, first 12 session-id characters, and loaded/registered hook state. JSON is {"machineEnforcement": <status>, "sessions": [...]}; the machine object has the same fields as enforcement status, and each session includes status, working directory, counts, enabled and disabled ids, and update time. The command only reads state.

Refusals and failures

A missing or unreadable control directory produces an empty result and exit 0. An invalid individual JSON file is retained as a row with parseError: true; an unreadable file becomes readError: true. These records are surfaced rather than causing a command-wide refusal.
