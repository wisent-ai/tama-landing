tama assignment show

Prints the operator's newest instruction for this machine, verbatim, and records that it has been read.

Invocation

tama assignment show [--json]

Takes no arguments. --json prints the whole record instead of the readable form. The record lives where TAMA_ASSIGNMENT_STATE names it, or beside the other Tama state.

Output and state

The readable form prints the session, when the instruction was captured, and its text exactly as it was written; the text is never summarised, because a summary is the reading model's interpretation and that is the thing this record exists to replace. Reading stamps the instruction's digest onto the record, which is what block-stale-assignment checks before a turn is allowed to end. A newer instruction supersedes the previous one by digest, so the stamp goes stale by itself when the operator says something new. The command exits 0.

Refusals and failures

  • An unknown subcommand prints usage: tama assignment show [--json] and exits 2.
  • With no instruction recorded yet the command says so and exits 0: a machine that has never seen a prompt has nothing to read, and that is not an error.
  • A record that cannot be written back is reported as cannot mark the assignment read: ... and exits 1, because a read that was not recorded would let a turn end on an unread instruction.
