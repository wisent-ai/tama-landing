tama adaptive

Opens the public adaptive-layer doctor command group for inspecting state, detecting drift, drafting repairs, and managing the legacy runner shim.

Invocation

tama adaptive <command> [...]

<command> is required and must be one of the linked leaf commands below.

Command tree

  • tama adaptive status
  • tama adaptive drift
  • tama adaptive queue
  • tama adaptive repair
  • tama adaptive apply
  • tama adaptive install
  • tama adaptive uninstall
  • tama adaptive claude-config

Output and state

The group itself performs no action. Read-only leaves inspect state or print configuration; repair stages proposal artifacts; apply and shim management can change live hook files.

Refusals and failures

A missing or unknown leaf prints the adaptive usage text beginning adaptive doctor <command> and exits 2. Leaf errors are prefixed doctor: and exit 1 unless the leaf documents a more specific refusal.
