tama adaptive status

Reports adaptive autonomy policy, per-hook effective state, source identity, and telemetry transport status.

Invocation

tama adaptive status

The command takes no required input or public options.

Output and state

The first line reports automatic ceiling, lexical-frustration behavior, explicit-correction behavior, and repair autonomy. Each sorted hook line includes tier, mode, phase, recovered baseline, open-run length, source verification, and whether a contested block was observed. The final telemetry= JSON reports open, ready, acknowledged, valid-ready, reclaimable, and legacy segments. The command is read-only and exits 0.

Refusals and failures

There are no command-specific policy refusals. Failures while loading or projecting adaptive state are written with the doctor: prefix and exit 1.
