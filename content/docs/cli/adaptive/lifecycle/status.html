tama adaptive status

Reports adaptive autonomy policy, per-hook effective state, source identity, and telemetry transport status.

Invocation

tama adaptive status [--json]

--json prints the same reading as one document instead of lines.

Output and state

The first line reports automatic ceiling, lexical-frustration behavior, explicit-correction behavior, and repair autonomy. Each sorted hook line includes tier, mode, phase, recovered baseline, open-run length, source verification, and whether a contested block was observed. The final telemetry= JSON reports the transport's segment counts. With --json the document is {policy: {autonomy, lexical, explicitCorrection, repair}, hooks: [{id, tier, mode, phase, baseline, openRun, source, contested}], telemetry}. The command is read-only and exits 0.

Refusals and failures

There are no command-specific policy refusals. Failures while loading or projecting adaptive state are written with the doctor: prefix and exit 1.
