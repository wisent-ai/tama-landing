tama adaptive queue

Lists repair proposals recorded in closed adaptive telemetry segments.

Invocation

tama adaptive queue [--json]

--json prints the recorded proposals as one document instead of lines.

Output and state

An empty queue prints exactly repair queue empty. Otherwise each repair-proposal event is printed with its ISO-8601 timestamp, hook id, repair kind, and evidence path; missing values render as unknown-time, ?, or -. With --json the document is {requests: [<each repair-proposal event as recorded>]}. The command does not acknowledge, remove, or apply queue entries and exits 0.

Refusals and failures

There are no command-specific policy refusals. An unreadable or invalid closed telemetry segment is reported with the doctor: prefix and exits 1.
