tama adaptive drift

Compares the SHA-256 content of every mapped live hook script with its source in the Tama archive.

Invocation

tama adaptive drift [--json]

--json prints the same comparison as one document instead of lines.

Output and state

For each catalog hook with an archived source path, Tama prints OK <hook-id>, DRIFT <hook-id> live=... archive=..., or MISSING <hook-id> live=... archive=.... With --json the document is {hooks: [{id, verdict, live, archive}], drifted}. It does not repair or copy any file. Exit 0 means every compared source exists and matches; any drift or missing side exits 1.

Refusals and failures

Missing live or archived files are reported as MISSING results rather than read errors. Other hashing or catalog failures are written with the doctor: prefix and exit 1.
