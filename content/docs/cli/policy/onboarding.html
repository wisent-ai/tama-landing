tama onboarding

The first-use walkthrough on the command line, and the inactive policy bundle it may adopt on the way in. The screens, the outcome they lead to and what first success means are on the Onboarding page; this page is the command.

Invocation

tama onboarding [--reset] [--policy-bundle <dir>] [--replace] [--home <path>]

Inputs and options

OptionMeaning
--resetDiscards the recorded walkthrough and replays it from its first screen
--policy-bundle <dir>Imports this bundle first, through the same validating transaction as tama policy import, and reports its result inside the walkthrough; the value must be a directory
--replaceLets that import overwrite a bundle already retained from the same source; meaningless without --policy-bundle
--home <path>The home whose walkthrough record and policy store are used instead of this account's; the value must be a directory

Output and state

Prints the walkthrough for a person and records how far it got, so a later run resumes rather than restarts; the bundle import, when asked for, is written before the walkthrough and never enables a hook. Exit 0 when the walkthrough ran; 1 with the walkthrough's own sentence when it could not.

Refusal boundary

A wrong invocation exits two before anything is read or written:

--policy-bundle requires a directory
--replace requires --policy-bundle <dir>
--home requires a directory
unknown onboarding option: <argument>
