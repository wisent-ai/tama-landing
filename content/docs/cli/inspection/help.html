tama help

Prints the sealed public top-level command summary.

Invocation

tama help
tama --help
tama -h
tama

The named command, both flag forms, and an invocation with no command select the same help path. It takes no required input or public options.

Output and state

tama help, --help and -h write usage beginning tama <command> and the public command list to stdout, perform no product action, and exit 0.

Help for one command

tama <command> [<verb>…] --help
tama <command> [<verb>…] -h

--help or -h answers for the deepest command the words before the first option name: tama violations --help prints every violations line of the summary, tama violations find --help only the violations find lines, each headed by tama <the command>, to stdout, exit 0, and never run the command: tama show --help does not look up a hook, and tama install --help installs nothing. A verb written as one of a <a|b|c> choice in the summary is answered with its entry; words after the deepest command (a hook id, a path) are its arguments. A verb the summary does not list answers with its group's lines, or with the group's own usage when the summary lists no line for the group.

Refusals and failures

The help path has no command-specific refusal. Any other unknown top-level command also prints the same usage, but exits 2 instead of 0.
