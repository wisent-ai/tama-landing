tama-cli build

Writes and reads the build and restart registry, ~/.shared-hooks/build_restart_registry.json. The gate block-unregistered-build-or-restart refuses a build or a restart that has no open entry here, and this command is the only writer.

Record an intent

tama-cli build record --kind build --target skarbiec \
  --reason "identity kind and duplicate refusal, suite green locally" \
  --revision 45a5c678042147f76241adf76fb7cf217e121ca6 [--minutes 60] [--json]

tama-cli build record --kind restart --target brama-desktop-model-router \
  --reason "the router holds a revoked credential and reads it once at start" \
  --minutes 30
OptionMeaning and refusal
--kindbuild or restart. Any other word is refused by name.
--targetThe product for a build, the service or unit for a restart. A build command that names no target of its own — stado release submit --source ., cargo build — is registered against the repository it runs in, which is the directory name the gate reports in its refusal.
--reasonAt least eight words, because the entry is read later by somebody who was not there. A shorter reason is refused and the word count is named.
--revisionRequired for --kind build, and it must be a full forty-character source revision. A build that cannot say what it carries is not recorded.
--minutesHow long the entry authorizes: one to two hundred forty minutes, sixty by default. A longer window is refused, so an entry nobody closes cannot become standing permission.
--homeThe home whose registry is written. Present so a test can drive the real command against a disposable registry instead of the operator's.

Recording the same kind and target again replaces that entry and reports the new expiry; entries for other targets keep their bytes.

Read and close

tama-cli build list [--json]
tama-cli build close --kind build --target skarbiec [--json]

list prints every entry with its kind, target, reason, revision, who recorded it and how many minutes it still authorizes; an expired entry is shown as expired, because the file keeps it until it is overwritten and it authorizes nothing. close removes one entry, which is what ends an authorization early; closing an entry that is not there is reported, not an error.

What the refusal looks like

BLOCKED: unregistered build: `stado release submit --source . --version 0.3.11` would
build skarbiec, and ~/.shared-hooks/build_restart_registry.json holds no open entry for
it. A build spends a builder the fleet has two of and a restart spends a service other
work depends on, so each is stated before it runs. Record the intent, then run the
command again:
  tama-cli build record --kind build --target skarbiec --reason "<what this build is
  for>" --revision <source revision this build carries>
