tama model-provider

Chooses the model service Tama's model calls ask — the objective reviewer, the stop review, frustration drafting and adaptive disputes. Brama is the default; a machine without Brama declares any OpenAI-compatible chat-completions service instead.

Invocation

tama model-provider [show] [--json]
printf '%s' "$KEY" | tama model-provider set --origin https://api.openai.com --model gpt-5 [--json]
tama model-provider unset [--json]

Output and state

set reads the service's API key from standard input only and writes the origin, model and key owner-only (mode 0600) to ~/.tama/model-provider.json; TAMA_MODEL_PROVIDER_PATH names another file. From then on every Tama model call posts to <origin>/v1/chat/completions with that key as its bearer and asks for that model. unset removes the file and Tama asks Brama again. Every verb prints the choice that stands afterwards: provider (brama or openai-compatible), model, and for a declared service origin and declaredIn, as key: value lines or as JSON with --json. The key is never printed.

Refusals and failures

  • set needs --origin URL and --model MODEL; the API key is read from standard input — exit 2.
  • --origin must be HTTPS, or HTTP on loopback, with no credentials, query or fragment, and --model must name a model: got "…" and "…" — exit 2.
  • the API key is read from standard input, and standard input was empty — exit 2.
  • no model provider is declared in <file>; Tama already asks Brama — unset with nothing declared, exit 1.
  • <file> names no complete model provider (origin, model and key); declare it again with `tama model-provider set` or remove it with `tama model-provider unset` — a damaged declaration; every model call refuses with the same sentence until it is repaired.
  • takes show, set or unset; got <verb> — exit 2.
