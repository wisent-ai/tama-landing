tama mcp-config

Prints the MCP client configuration fragment for Tama's native MCP server.

Invocation

tama mcp-config

The command takes no required input or public options.

Output and state

Stdout receives a JSON document whose mcpServers.tama.command is the running tama program and whose args are ["mcp"]: the MCP server is the tama mcp subcommand of the same program. When the running program cannot name its own path, the command is the bare name tama. It never writes client configuration.

Refusals and failures

There are no command-specific policy refusals. The bare-name answer is valid output rather than a missing-server error; actual server discovery occurs when the client starts that command.
