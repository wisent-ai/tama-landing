tama justify

Records, reads and retires the justifications the write guards require, so a registry that a hook demands is written by a command instead of by hand.

Invocation

tama justify <record|show|remove|list> [--file <path>] [--justification <text>]
             [--kind file|test] [--quote <text>] [--expires-at <iso>] [--home <path>] [--json]

--kind selects the registry: file for ~/.shared-hooks/file_justifications.json, which the new-file rule reads, and test for ~/.shared-hooks/test_justifications.json, which additionally requires --quote, the operator's own words asking for that test. --home points both registries at another home, which is how the tests drive the command against an isolated one.

Why it exists

The rules that demand a justification are enforced on write, and the registries they read are long — the file registry passed seven thousand lines. A guard that refuses any edit leaving a source file over three hundred lines therefore refused every edit to the registry that another guard demanded an entry in, so the two rules together made the required entry unwritable. The command owns those files instead: it is not an exemption from either rule, it is the supported way to satisfy one of them.

Output and state

record writes or replaces one entry keyed by the absolute path and reports which registry it wrote. show prints one entry, list prints the paths a registry holds, and remove retires one entry. --json emits the same answers as one object. Each write replaces the registry atomically, so a failed write leaves the previous content intact.

Refusals and failures

A justification shorter than the rule's own word count is refused with the count it needs. A test justification whose --quote is not a verbatim user message in the stored transcripts is refused, and so is one whose justification text does not contain that quote — the same two checks the write guard performs, so the command cannot record an entry the guard would then reject. A missing --file, an unknown subcommand and an unreadable registry print usage and exit non-zero.
