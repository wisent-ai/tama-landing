Examples

Runnable, commented shell scripts, one bounded CLI outcome each. Every script states whether it reads or mutates before its first command; mutation scripts require explicit environment inputs before they act. The command surface is documented in docs/cli.md; the two integrity scripts are executed end-to-end with pasted output in the walkthroughs.

Read-only scripts assume the sealed tama CLI on PATH (getting-started/install-cli.sh links it from the installed Tama.app named by TAMA_APP). A script that needs an input names it and stops until it is set: core/hooks-list.sh inspects the hook HOOK_ID names, and integrity/runtime-status.sh asks the CLI TAMA_CLI names (in a checkout, the release inside .build/Tama.app) about the home TAMA_HOME names. None of them picks a value for you.
