Learned screen

What Tama learned across every agent session, as proposals to decide on. The engine is the sealed CLI's tama rules digest, run as tama request rules/digest, so the screen and the terminal show the same proposals.

What a row shows

  • The hook or drafted rule the proposal is about.
  • What the evidence says: how often the operator contested the hook, or the message the drafted rule refuses with and the quote it was drafted from.
  • How many pieces of evidence, the first and the last.
  • The command that acts on it, selectable for pasting: tama adaptive repair <hook> or tama rules remove --id <rule>.

Dismiss until new evidence

The button runs tama request rules/dismiss with the proposal's id and the operator's approval for that one request. The proposal leaves the screen and comes back when more evidence arrives than it had. A refusal is shown as the command's own sentence.

When a source cannot be read

A source Tama could not read — the adaptive evidence, for instance — is shown as a red panel with its error above the proposals, and the other proposals are still listed.

The screen is under Policy and needs policy control, like the build registry.
